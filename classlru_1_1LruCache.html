Detailed Description

template<class Key, class Value, class Hash = std::hash<Key>>
class lru::LruCache< Key, Value, Hash >

Fixed-capacity least-recently-used cache.

Template Parameters
Keykey type, must be hashable by Hash and copyable
Valuevalue type, copied on insert and returned by value on lookup
Hashhash functor for Key

All public member functions are thread-safe: a single mutex guards the list and the index. This trades throughput for simplicity on purpose; see the benchmark for the numbers.
